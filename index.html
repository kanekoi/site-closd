☁️ Cloud sync — all your devices, live

        

          One-time setup (about 5 minutes). After that, every change on your phone appears on your PC
          in about a second — and vice versa. Both devices must use the same sync code.
        

        

          
          
          
          
        

        

          
          
        

        

        

          📖 One-time setup guide (click to open)
          
    
            
  1. Go to console.firebase.google.com and click Add project (any name, disable analytics).
    2. 
            
  2. In the left menu: Build → Realtime Database → Create Database → pick a location → Start in test mode.
    3. 
            
  3. Go to Rules tab and paste:
              
    {
  "rules": {
    "school-hub": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}
    
              then click Publish.
    4. 
            
  4. Go to Build → Authentication → Get started, enable the Anonymous provider.
    5. 
            
  5. Click the ⚙️ gear → Project settings → under "Your apps" click the </> (Web) icon → register the app (no hosting needed).
    6. 
            
  6. Copy apiKey, databaseURL and projectId from the shown config into the fields above, invent a sync code, and click Connect sync — on every device.
    7. 
          

          
Keys are saved only in your browser's storage — they are never written into your website files or your GitHub repo.
